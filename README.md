# Apex Excellence Academy — Training Tools

Interactive tools for the Apex Excellence Academy, a 12-week leadership development program for Apex concierge professionals.

## What's in here

- **AEA_App.html** — the agent app: week feed, scenario trainer, weekly reflections, commitment, progress profile, and a Send to Facilitator progress file.
- **AEA_Leadership_Self_Assessment.html** — 18-question self-assessment across 6 leadership dimensions. Results save on the agent's phone and appear in the app's Progress screen.

## Privacy

Everything an agent enters stays on their own device until they choose Send to Facilitator. No names or personnel data are stored in this repository.

## Program settings

The cohort name and start date are set at the top of the script in `AEA_App.html` (`PROGRAM`).
